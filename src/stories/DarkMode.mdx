# Dark Mode

Dark mode is controlled via the `useSenam` hook and is fully compatible with the shadcn/ui theming approach.

## Usage

Access the current theme and update it using `useSenam`:

```tsx id="m1z9kp"
import { useSenam } from "senam-ui";

export function ThemeToggle() {
  const { theme, setTheme } = useSenam();

  return <button onClick={() => setTheme("dark")}>Enable Dark Mode</button>;
}
```

## Available Themes

- `"light"` → Light mode
- `"dark"` → Dark mode
- `"system"` → Follows system preference

## Notes

- Uses the same `dark` class strategy as shadcn/ui.
- Works seamlessly with shadcn color utilities and Tailwind setup.
- Theme is applied globally via the `<html>` element.
- The selected theme is persisted in `localStorage`.
